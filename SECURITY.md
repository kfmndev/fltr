# Security Policy

## Supported versions

Only the latest released version of fltr receives security fixes.

## Reporting a vulnerability

Do **not** open a public issue for a suspected vulnerability.

Use GitHub's private vulnerability reporting: on the repository, go to **Security → Report a vulnerability**. If you cannot use it, contact the maintainer [@kfmndev](https://github.com/kfmndev) through their GitHub profile and ask for a private channel before sharing details. Include:

- a description of the issue and its impact
- steps to reproduce (commands, configuration, request samples)
- affected versions

Please keep the details confidential until a fix is released. We will acknowledge reports as quickly as we can, work on a fix, and credit you in the release notes if you wish.

## Scope

fltr is a reverse proxy: the highest-value areas are rule-matching bypasses and the proxying behavior itself.
