# AGENTS.md

## Agent skills

### Unslop

Keep changes and responses concise, specific, and grounded in the request; remove filler, vague wording, unnecessary abstraction, and unrelated edits. Apply this to all work in the repository.

### Issue tracker

Issues are tracked in this repo's GitHub Issues via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical labels, strings equal to their names: needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
